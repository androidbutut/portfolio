# Endang Saepudin — 3D Portfolio

**Interactive 3D Route / Cybernetic Garage & Highway Journey**

Portfolio web 3D modern & futuristik untuk Endang Saepudin (Professional Driver).

## Tech Stack

- Vite + React 19 + TypeScript
- Three.js + @react-three/fiber + @react-three/drei
- Framer Motion + GSAP
- Tailwind CSS v4
- Web Audio API (sound FX)

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:5173`

## Fitur

- Infinite cyberpunk highway 3D
- GSAP camera path on scroll
- Sound FX toggle (engine + whoosh)
- 3D vehicle carousel (OrbitControls)
- Experience timeline + filter
- Glassmorphism HUD
